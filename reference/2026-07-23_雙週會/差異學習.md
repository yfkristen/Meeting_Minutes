# 初版草稿 → 最終定稿：差異學習筆記

比對 Claude 初版與使用者定稿，歸納出的格式與風格規則（已回寫進 templates/ 與 CLAUDE.md）。

## 1. 開頭固定格式（保留）
```
各位主管好：

檢送{YYYY/MM/DD(週別)}「{完整會議名稱}」會議紀錄，敬請參閱。
```
- 會議全名：`金控AI推動委員會PMO待辦事項討論例會`

## 2. 大項結構調整（重要）
- 初版：壹＝會議宗旨、貳＝會議安排、參＝討論議題
- 定稿：**壹＝會議時間、貳＝與會人員、參＝討論議題與會議紀要**
- 「會議目的」與「會議安排」不再是壹貳，而是收進「參」底下的「一、二」
- 壹貳僅放會議基本資訊（時間、與會者）

## 3. 會議時間格式
- `2026/7/23(四) PM4:00-5:20`（用 PM，時分用冒號，起訖用半形連字號）
- 注意實際時間是 16:00–17:20，不是原排定的 17:00；以逐字稿/使用者提供為準

## 4. 與會人員
- 逐一列出全名，頓號分隔
- 請假者於名字後括號註記原因：`歐黛瑩(會議衝堂請假)`
- 定稿名單：邱錦瑩、柯燕茹、劉彥甫、劉宜依、唐可芹、葛世豪、黃啟龍、歐黛瑩(會議衝堂請假)、張淑宜、翁詩茵

## 5. 用語正式化（明顯偏好）
- 「會議目的」段落大幅書面化、公文化，多用四字語與並列結構
  - 定稿：「鑑於專案推動涉及多元溝通與交辦管道，為提升資訊整合效率並強化跨單位協作，本會議將作為 PMO 進度對齊與資訊共享平台，定期彙整重要事項、同步執行進度，確保各項決議與訊息傳達一致，及提升整體專案推動效率。」
- 機制段標題：「建立工作**同步**機制」（非「追蹤」）
- 條列句尾用「請…」的請託語氣：「請各位自行新增交辦事項」「已完成者請標示『已完成』」

## 6. 各案進度：每項結尾標註負責人
